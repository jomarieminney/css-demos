How the stylesheet is put together

One stylesheet. Its first line declares the cascade order, and every rule after it lives inside a named layer. Each demo's rules sit under their own heading in the demo layer, so you can read a demo top to bottom in one place.

  • reset undo browser defaults
  • theme brand tokens
  • base page canvas
  • components masthead, menu, cards, badge
  • demo one heading per page
  • utilities helpers that always win
  • prefs reduced motion, last word

Between pages

  • @view-transition pages cross-fade, the badge and slab morph
  • @container the floof profile adapts to its card, not the viewport
