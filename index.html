How the stylesheet is put together

One shared main.css declares the cascade order, then @imports each file into its layer. Every demo page adds its own file into the demo layer.

  • reset undo browser defaults
  • theme brand tokens
  • base page canvas
  • components masthead, cards, badge
  • demo one file per page
  • utilities helpers that always win
  • prefs reduced motion, last word

Between pages

  • @view-transition pages cross-fade, the badge and slab morph
  • @container the floof profile adapts to its card, not the viewport
