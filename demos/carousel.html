Progressive enhancement, live

What this browser is giving you right now. Every tick is decided by @supports, not JavaScript. The maths the JavaScript version does on every click is a handful of calc()s here, and the browser tweens them.

CSS · graded live by @supports

  • :has() the checked radio sets --active on the whole reel
  • sign() / abs() offset → tilt, scale, depth, stacking
  • round() wraps the offset, so the ring is endless
  • linear() springy easing on every move
  • rotate / scale / translate individual transform properties
  • @layer cascade order · no layers, no styles at all

Full disclosure: the state lives in a radio group, so a screen reader hears six radio buttons rather than a carousel. The upside is that arrow keys move between slides for free.
