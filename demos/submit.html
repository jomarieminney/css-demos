Progressive enhancement, live

What this browser is giving you right now. Every tick is decided by @supports, not JavaScript. The form works everywhere; the styled dropdown and the growing textarea are the newest parts, and without them you get the browser's own select and a textarea you can drag.

CSS · graded live by @supports

  • :placeholder-shown empty or not: the label floats
  • :user-invalid red only after you've had a go
  • :has() each field restyles itself from its control
  • appearance: base-select a dropdown you can style
  • field-sizing: content the textarea grows as you type
  • ::file-selector-button the "choose file" button, restyled
  • accent-color the checkbox in brand colours

HTML · CSS can't grade these, so check Can I use

  • required, type="email", minlength the browser checks the form
  • command / commandfor the button opens the dialog
  • type="range" a real slider, restyled
  • <selectedcontent> the chosen option, copied into the button
