Progressive enhancement, live

What this browser is giving you right now. Every tick is decided by @supports, not JavaScript. Open it in another browser and compare.

CSS · graded live by @supports

  • ::details-content animate open and close
  • interpolate-size glide to height: auto
  • @starting-style cards enter on load
  • :has() dim the others
  • linear() springy easing
  • background-clip: text gradient names

HTML · CSS can't grade these, so check Can I use

  • <details name="…"> one open at a time
  • <details> + <summary> the disclosure itself
