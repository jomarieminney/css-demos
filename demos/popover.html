04 · Popover · popover + anchor positioning

Peekaboo Floofs

Each face is an anchor. Its popover is tethered to it with position-anchor, placed with position-area, and given a list of fallbacks to try when it would run off screen.

Every popover asks to sit to the right of its face. The faces on the right have no room there, so theirs flip left; open one near the bottom of the window and it flips up.

Progressive enhancement, live

What this browser is giving you right now. Every tick is decided by @supports, not JavaScript. The popover attribute gives you the top layer, light dismiss and Escape; anchor positioning does the geometry.

CSS · graded live by @supports

  • anchor-name / position-anchor tether a popover to its button
  • anchor() pin the connecting line to the first and last face
  • position-try-fallbacks flip when it would overflow
  • @position-try a custom last resort: centre it
  • :popover-open style the open state
  • @starting-style popovers scale in
  • transition-behavior: allow-discrete and scale back out
  • @container the profile stacks in a 24rem popover
  • @layer cascade order · no layers, no styles at all

HTML · CSS can't grade these, so check Can I use

  • popover top layer, light dismiss, Escape
  • popovertarget open it from a button

Without anchor positioning the popover still opens, centred in the viewport like any popover. That is the fallback, and it is fine.
